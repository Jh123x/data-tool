# Data Tool

A convenient data tool to help with format conversions.

## Features

- Conversion between all supported types
- 2 clicks to get converted data
- Copy and Download Results
- View Results (Note: For large results, the webpage may lag)

![Video](./docs/main.mp4 "Main product video")

## Supported Types

- JSON
- TSV
- CSV
